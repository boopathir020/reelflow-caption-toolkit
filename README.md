# ReelFlow Caption Toolkit

A simple open-source caption helper for short-form video editors.

## Features

- Splits long text into readable caption lines.
- Lets users choose a maximum character limit per line.
- Includes a simple command-line interface.
- Built as a starting point for future editing workflow automation.

## Requirements

- Python 3.8 or later
- No third-party Python packages required

## How to use

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python3 caption_tool.py
```

4. Enter your reel script when prompted.
5. Choose the maximum number of characters per line.
